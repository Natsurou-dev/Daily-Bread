# Daily Bread

Daily Bread is a simple web application that displays a different Bible verse for each day of the month. This was my first official web app. I am a Christian and am drawn to these sorts of applications, so I wanted to build something I and my family could use daily. 

## Features

* Displays a daily Bible verse based on the current date with a unique background.
* Shows the verse in multiple Bible translations.
* Responsive design for both mobile and desktop.

## Technologies

* HTML5
* CSS3
* JavaScript (Vanilla)
